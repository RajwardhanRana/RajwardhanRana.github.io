The bar chart adapts the official simple bar example: changed title, teal colour, larger axis labels and swapped axes. Its example values are replaced with India inflation data.

The time series adapts the official line example. Changes include title and source subtitle, colour, line thickness, point markers, axis titles, label sizes, year formatting, lighter gridlines, tooltips and responsive width.

Week 3: Python, Altair and stock-market valuation

Can a price-to-earnings ratio tell us whether US stocks are expensive? This chart uses Python to clean Robert Shiller's monthly data and Altair to generate the visualisation.

Chart 6: US stock prices relative to earnings

The dashed line is the mean of the 1,866 valid monthly P/E ratios from January 1871 to June 2026: 16.22 times. The latest usable observation in this teaching snapshot is 25.22 times (June 2026).

The largest observed ratio is 123.73 in May 2009. During the financial crisis, earnings collapsed towards zero, pushing up P/E even as prices fell. A high ratio alone does not establish that stocks are overvalued. This is ordinary P/E, not the cyclically adjusted P/E (CAPE).

Source: Robert Shiller, using the Class 3 course handout. Snapshot prepared 23 October 2026; it is not live market data. The last four rows lack usable earnings and are excluded.

Class 3: data preparation and chart styling

The notebook uses requests to fetch the CSV, reads Date as text, calculates P/E = P / E, removes missing or non-finite ratios, checks duplicate months and exports ISO dates. The original fields are preserved in the full cleaned CSV. October dates are checked explicitly.

Altair builds the line chart and layers a dashed average rule. Customisations include teal colour, a thicker line, descriptive title, responsive width, larger axis labels, units and hover tooltips. The exported JSON links to the cleaned CSV.

Chart 7: Exploring total fertility rates

Total fertility rate is measured in births per woman. It summarises current age-specific fertility rates, rather than predicting an individual woman's completed family size. Use the selector below the chart to compare countries.

Source: World Bank WDI: SP.DYN.TFRT.IN, drawing on UN World Population Prospects, national statistical offices and Eurostat. Annual observations; coverage and historical estimates may be revised. Class 4: how the API chart works

The URL combines a base endpoint, four country codes and the indicator code. The options request JSON and up to 1,000 observations, enough for the current four annual series. No API key is needed.

The response is [metadata, observations]. The chart uses "format": {"type": "json", "property": "[1]"} to select the observations. It removes null values rather than converting them to zero, parses years in UTC and filters the selected country.

The notebook uses requests, pandas.json_normalize and Altair to inspect and chart the same data. It checks pagination and duplicate country-year pairs, exports a cleaned snapshot CSV and tries India's life-expectancy series. These downloadable CSVs are snapshots from 23 October 2026; the displayed chart reads the live API instead.
